# Changelog

## [1.5.0-beta] — 2026-05-24

### План развития: 200 улучшений

Подготовлен детальный план развития проекта с 200 улучшениями, разбитыми на две категории:

- **100 улучшений кода и производительности** — архитектура, БД, API, React-оптимизация, безопасность, GLONASS-интеграция
- **100 улучшений дизайна и отображения** — мобильный UX, загрузка, визуальная консистентность, доступность, анимации, визуализация данных

Полный документ: `docs/fleet-tracker-200-improvements.pdf`

### Дизайн

- **Карточка компании**: приведена к единому стилю остальных форм (сотрудник, экипаж)
  - Добавлен цветной акцент `border-l-4 border-l-emerald-500` на DialogHeader
  - Секции обёрнуты в `CollapsibleSection` с иконками и шевронами сворачивания
  - Секция «Адреса» по умолчанию свёрнута
  - Красная звёздочка для обязательного поля «Название»
  - Добавлены иконки `ChevronDown`, `ChevronUp` и компонент `Badge`

## [1.4.0-beta] — 2026-05-23

### Дизайн

- **Единый дизайн-стандарт**: все формы и диалоги приведены к общему паттерну
  - `border-l-4` цветные акценты: сотрудник = violet, экипаж = sky
  - `CollapsibleSection` для секций формы сотрудника
  - Валидация с `AlertTriangle` и красной звёздочкой для обязательных полей
  - `AlertDialog` для несохранённых изменений во всех формах
  - Категории ВУ как интерактивные кнопки-чипы

### Рейсы — 100 улучшений

- Полная переработка вкладки «Рейсы»
- Карточки рейсов с цветовой индикацией статуса
- Детальный диалог рейса с табами, треком на карте, датчиками
- Форма создания/редактирования с автозаполнением
- Интеграция с GLONASS: старт/завершение рейса из трекера

## [1.3.1-beta] — 2026-05-22

### Мобильные улучшения

- Замена всех `vh` на `dvh` для корректного отображения на мобильных браузерах
- `max-h-[98dvh]` для всех диалогов и форм
- Мобильная навигация с иконками и FAB-кнопкой
- Адаптивные заголовки и статистика

### Исправления

- Замена несуществующей иконки `Screenshot` на `ImageDown` в map-tab
- Исправление hydration mismatch в `loadPrefs()` через `useEffect` + `prefsLoadedRef`
- Копирование static-файлов после build
