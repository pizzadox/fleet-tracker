## [1.6.0-beta] — 2026-05-25

### GLONASS: максимальная скорость обновления датчиков

Полная оптимизация конвейера обновления данных GLONASS — от API до UI. Синхронизация ускорена в 3–10 раз.

#### Новый эндпоинт `/api/glonass/quick-sync`

- Быстрое обновление датчиков **одного трекера** за 1–2 секунды
- Параллельный запрос деталей объекта и метаданных датчиков (`Promise.all`)
- Bulk `createMany` вместо N отдельных `create` (20 датчиков = 1 SQL-запрос вместо 20)
- Пропускает обратное геокодирование и статистику — только позиция и датчики
- Возвращает обновлённые данные для мгновенного обновления UI

#### Оптимизация `/api/glonass/sync`

- **Параллельная обработка трекеров** — до 5 трекеров одновременно через `Promise.allSettled` с concurrency limit
- **Fast mode** (`?fast=true`) — пропускает геокодирование и статистику, обновляет только позицию и датчики
- **Bulk `createMany`** — все датчики трекера записываются одним SQL-запросом
- **Логирование времени** — в консоли и в ответе API: `elapsedMs`, `mode: 'fast' | 'full'`
- Автообновление (60 сек) теперь использует fast mode по умолчанию

#### Оптимизация `/api/glonass/sensors`

- Замена N×`create` на `createMany` с `skipDuplicates` — единичный bulk INSERT

#### Кнопка быстрого обновления в карточках

- Каждая карточка техники на вкладке «Карта» получила кнопку 🔄 «Обновить датчики»
- Работает в обоих режимах: расширенном и компактном
- Показывает спиннер во время обновления
- Toast показывает время синхронизации: `Синхронизация: 5 из 5 (2.3с)`

#### Ожидаемое ускорение

| Операция | До | После |
|----------|-----|-------|
| Полная синхронизация (10 трекеров) | ~50 сек | ~10–15 сек |
| Быстрая синхронизация (fast mode) | ~50 сек | ~5–8 сек |
| Обновление одного трекера | ~5 сек | ~1–2 сек |
| Запись датчиков в БД (20 шт) | 20 запросов | 1 запрос |

### Система настраиваемых панелей

- Компоненты для управления панелями на страницах: добавление, перемещение, удаление
- `PanelRegistry` — реестр доступных панелей с метаданными
- `usePanelConfig` — хук для управления конфигурацией панелей вкладки
- `PanelManagerDialog` — диалог настройки панелей (добавить/скрыть/переместить)
- `PanelWrapper` — обёртка с drag-handle и кнопками управления
- `PanelSection` — секция с заголовком и сворачиванием
- `TabPanelProvider` — контекст для управления панелями вкладки
- Интегрировано во все основные вкладки: Техника, Ремонты, Рейсы, Управление
