## Возможности

### 🔧 Техника и оборудование

- Полный учёт автотранспорта и спецтехники с **40+ полями** на единицу
- **27 типов техники** в 7 категориях: автомобили, грузовики, спецтехника, прицепы, водный транспорт и др.
- **Статусы**: активна, на ремонте, списана, в аренде, зарезервирована
- **Состояние**: отличное, хорошее, удовлетворительное, плохое
- VIN, СТС, ПТС, страховка, номер, категория, цвет, двигатель, пробег, топливо, грузоподъёмность
- Финансы: цена покупки/текущая, аренда (стоимость, даты), страховка
- ТО: дата последнего/следующего, интервал, норма расхода, замена шин/масел
- Фотографии по категориям: общие, документы, повреждения, ремонт
- История изменений с типами событий (регистрация, статус, передача, аренда, ремонт, ГЛОНАСС)
- Назначение нескольких сотрудников на единицу техники
- Представления: карточки, таблица, канбан-доска
- Фильтры: поиск, статус, тип, состояние, владелец, арендатор + быстрые фильтры
- Экспорт в CSV

### 🗺️ Карта и ГЛОНАСС

- **Интерактивная карта Leaflet** с кластерами маркеров
- Кастомные маркеры: иконка типа техники, направление движения, госномер, статус онлайн
- **Авто-обновление** с настраиваемой скоростью: 5с, 10с, 15с, 30с, 1м
- **Индикатор свежести данных**: зелёный (< 30с), жёлтый (30с–2м), красный (> 2м)
- Панель фильтров: онлайн/офлайн/без трекера, тип техники, поиск, сортировка
- Боковая панель деталей техники с данными трекера и датчиками
- Просмотр исторических треков с аналитикой
- Скриншот карты в PNG, полноэкранный режим, легенда
- **Инкрементальное обновление** — маркер перемещается без перерисовки карты
- **Тихая синхронизация** — данные обновляются без спиннера и разрушения контента

### 📡 Axenta.cloud — ГЛОНАСС интеграция

- Авторизация: логин/пароль, автоматическое обновление токена
- **Полная синхронизация**: мониторинг, объекты, датчики, статистика, геокодирование
- **Быстрая синхронизация** (`?fast=true`): только позиция и датчики, без геокодирования
- **Живой API** (`/api/glonass/live`): реальное время без записи в БД
- **Параллельная обработка**: до 5 трекеров одновременно
- **Bulk-записи** датчиков: 1 SQL-запрос вместо 20
- Датчики по категориям: топливо, зажигание, температура, пробег, напряжение, цифровые, прочие
- Команды трекеру: список доступных, отправка, отслеживание доставки
- Треки за произвольный период: поездки, стоянки, остановки, заправки, сливы
- Статистика: пробег, скорость, топливо, моточасы
- Снимок: топливо/пробег/адрес на конкретный момент (5 источников с fallback)
- Геокодирование: Axenta → Nominatim (OSM) fallback
- Определение онлайн/офлайн: порог 30 минут + connectedStatus
- XLSX-отчёт по датчикам (многолистовой Excel)

### 🔨 Ремонты

- CRUD с **20+ полями**: описание, статус, приоритет, тип, стоимость, подрядчик, даты
- **Многоэтапный workflow** с шаблонами (диагностика, разборка, запчасти, ремонт, сборка, тестирование, покраска, сдача)
- Назначение мастеров/ассистентов/наблюдателей из сотрудников
- Фотографии по категориям: до/во время/после/документы, с привязкой к этапу
- Комментарии с авторством
- Дублирование ремонтов
- Kanban-доска, сортировка по любому полю

### 🚛 Рейсы и маршруты

- CRUD с полной информацией: маршрут, груз, расстояние, топливо, пробег, стоимость, выручка
- **GLONASS-аналитика** (автозаполнение при завершении): средняя/макс. скорость, расход топлива, моточасы, заправки, сливы, простои
- **Шаблоны маршрутов**: переиспользуемые определения с точками, автоподсчёт расстояния
- **Оптимизация маршрута**: nearest-neighbor алгоритм для перестановки точек
- **Печать рейса**: A4 HTML-отчёт с растровой картой и треком (генерация через Sharp)
- Маршрутные точки: координаты, плановое/фактическое время, расстояние

### 👥 Сотрудники

- Кадровый учёт: ФИО, должность, телефон, email, дата рождения, адрес
- Водительское удостоверение: номер, категория (B, C, D, CE...), срок действия
- Паспортные данные, зарплата, даты найма/увольнения
- Статусы: активен, уволен, отпуск, больничный
- Привязка к экипажу и/или технике
- Назначения на ремонты видны в карточке сотрудника

### 👨‍👩‍👧‍👦 Экипажи

- CRUD для экипажей/бригад
- Типы: водительский, механиков, смешанный
- Управление составом: добавление из справочника или ручной ввод
- Роли участников: водитель, механик, помощник, грузчик
- Привязка к рейсам

### 🏢 Компании

- CRUD для компаний-владельцев и арендаторов
- Юридические данные: ИНН, КПП, ОГРН
- Адреса: юридический, фактический
- Контакты: телефон, email, директор
- Счётчики: техника в собственности, в аренде

### 🔔 Уведомления

- **6 типов правил** на единицу техники:
  - `offline` — трекер офлайн
  - `not_synced` — нет данных N часов
  - `not_moving` — скорость 0 более N часов
  - `speed_exceeded` — скорость выше порога
  - `fuel_low` — топливо ниже порога
  - `zone_exit` — выход из зоны (заглушка)
- Настраиваемые пороги для каждого правила
- Cooldown 30 минут для предотвращения повторов
- Колокольчик с бейджем, выпадающий список, toast-уведомления
- Автопроверка каждые 60 секунд

### 🔐 Авторизация и роли

- **PIN-авторизация**: 4–6 цифр, SHA-256 хэширование
- **5 ролей**: Администратор, Менеджер, Диспетчер, Ремонтный рабочий, Рабочий
- **12 прав доступа**: equipment, repairs, trips, employees, companies, crews, map, settings, users (чтение/запись)
- Динамические права из БД, редактируемые администратором
- Сессии: cookie-based, 7-дневный срок, серверные токены

### 🖥️ Система панелей

- **30+ настраиваемых панелей** по всем вкладкам
- Сворачиваемые секции с drag-handle
- 5 пресетов сценариев: Полный, Диспетчер, Механик, Менеджер, Минималист
- Менеджер панелей: добавить/скрыть/переместить
- Конфигурация сохраняется в localStorage

### 🔍 Глобальный поиск

- **Ctrl+K** — быстрый поиск по всей системе
- Поиск по: Техника, Ремонты, Рейсы, Сотрудники, Компании
- Цветовое кодирование результатов по типу
- Навигация клавиатурой

### 📊 Дашборд и статистика

- Шапка: всего техники, активной, на ремонте, в аренде, онлайн-трекеров, рейсов, ремонтов, компаний
- Вкладка техники: стоимость парка, распределение по состоянию, утилизация
- Вкладка ремонтов: всего/в работе/завершено, стоимости, топ ремонтируемой техники
- Вкладка карты: онлайн/офлайн, средняя скорость, топливо, пробег

### 🌙 Тёмная тема

- Полная поддержка тёмной темы через `next-themes`
- Переключатель в шапке
- Все компоненты совместимы с тёмной темой

### 📱 Мобильная адаптация

- `dvh`-единицы для корректного отображения в мобильных браузерах
- Мобильная навигация: нижнее меню с иконками
- FAB-кнопка для быстрого добавления
- Адаптивные статистика, заголовки, диалоги
- `max-h-[98dvh]` для всех диалогов

## API-эндпоинты

### Техника
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/equipment` | Список техники (фильтры: поиск, статус, тип, состояние, владелец, арендатор) |
| POST | `/api/equipment` | Создать технику |
| GET | `/api/equipment/[id]` | Детали техники (с владельцем, фото, ремонтами, историей, трекерами) |
| PUT | `/api/equipment/[id]` | Обновить технику |
| DELETE | `/api/equipment/[id]` | Удалить технику |
| GET/POST | `/api/equipment/[id]/photos` | Фотографии техники |

### Продакшен (пустая БД, только администратор)

Для продакшен-окружения используется отдельная база данных `db/production.db`, которая содержит **только одного пользователя — Администратора** с PIN `1234` и набор прав по умолчанию. Все остальные таблицы (техника, ремонты, рейсы и т.д.) пусты.

### Переменные окружения

Проект использует два файла окружения:

| Файл | Назначение | DATABASE_URL |
|------|-----------|-------------|
| `.env` | Разработка (загружается при `next dev`) | `file:./db/dev.db` |
| `.env.production` | Продакшен (загружается при `next start`) | `file:./db/production.db` |

Оба файла уже созданы в репозитории. При необходимости можно изменить путь к БД:

```env
# .env — для разработки
DATABASE_URL="file:./db/dev.db"

# .env.production — для продакшена
DATABASE_URL="file:./db/production.db"
```

## Интеграция с Axenta.cloud

1. Откройте **Настройки → ГЛОНАСС** в приложении
2. Заполните поля:
   - **API URL** — адрес вашего Axenta-сервера (например, `https://demo.axenta.cloud`)
   - **Имя пользователя** и **Пароль** — учётные данные Axenta
   - **API-ключ** — если есть готовый токен
3. Включите интеграцию переключателем «Активна»
4. Нажмите **Синхронизировать** для загрузки данных трекеров
5. Привяжите объекты Axenta к единицам техники через кнопку «Подключить трекер»

### Режимы синхронизации

| Режим | Эндпоинт | Скорость | Что обновляет |
|-------|----------|----------|---------------|
| Полная | `POST /api/glonass/sync` | ~10–15с (10 трекеров) | Позиция, датчики, геокодирование, статистика |
| Быстрая | `POST /api/glonass/sync?fast=true` | ~5–8с | Позиция, датчики (без геокодирования) |
| Один трекер | `POST /api/glonass/quick-sync` | ~1–2с | Позиция, датчики одного трекера |
| Живые данные | `GET /api/glonass/live` | ~500мс | Позиция, датчики (без записи в БД) |
